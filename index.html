3. Algoritmo 1 — Eleição de Líder em Anel (Chang-Roberts)

3.1 Objetivo

Implementar o algoritmo de eleição de líder baseado em Chang-Roberts utilizando uma topologia em anel.

3.2 Descrição do Algoritmo

Cada processo possui:

  • Identificador (pid) único entre 0 e N-1
  • Variável local leader_id
  • Variáveis msg e am_i_candidate

3.3 Decisões de Implementação

  • Envio de mensagens entre processos
  • Diferença entre identificador SMPL e pid lógico
  • Representação do anel via índice modular
  • Contagem de mensagens trocadas

4. Algoritmo 2 — Randomized Leader Election Algorithm

4.1 Objetivo

Implementar o algoritmo aleatorizado de eleição de líder baseado em anel.

4.2 Descrição do Algoritmo

O algoritmo funciona em rodadas.

Em cada rodada, os processos candidatos sorteiam um valor aleatório para um bit.

  • Processos com bit = 1 permanecem candidatos
  • Processos com bit = 0 deixam de ser candidatos
  • Mensagens circulam ao redor do anel
  • O algoritmo termina quando resta apenas um candidato

4.3 Decisões de Implementação

  • Uso da função rand()
  • Execução baseada em rodadas
  • Contagem de mensagens trocadas
  • Representação lógica em anel

4.4 Estruturas de Dados

typedef struct {
    int pid;
    int leader_id;
    int active;
    int bit;
} process_t;

4.5 Execução

cd randomized-election

make

./lider_random
